---
name: Technician mobile delivery
description: The agreed rollout order for putting the technician portal on phones.
---

Use an installable Progressive Web App as the first mobile delivery channel for technicians, while keeping a separate native iPhone/Android app as a later phase.

**Why:** The user explicitly chose a PWA-first rollout so technicians can get home-screen access quickly without duplicating the existing portal and backend.

**How to apply:** Keep core technician workflows usable in the responsive web portal. Treat app-store distribution, background location, and deeper native notification support as a later mobile-artifact decision.
